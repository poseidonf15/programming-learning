What is a Database?
A Database is some kind of object that stores data.
What is a Table?
A Table is a data kind where the data is stored into Columns and Records.
What is a Column?
A Column is part of the Table that stores specific type of information like id or title. 
What is a Record?
A Record is a row inside of the Table that stores the information of an object via given information titles.
What is SELECT?
SELECT is a command that lets us 'grab' information from a table.
What is FROM?
FROM is a command to set the table that we want to get the information from.
What is *?
* can be used with SELECT to 'grab' all of the information in the desired table.
